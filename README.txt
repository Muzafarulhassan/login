NOVA LOGIN & LOGOUT — QUICK START

FILES
- index.html       Login page
- dashboard.html   Protected demo dashboard
- style.css        Responsive glass/neon design
- script.js        Demo login session and logout behavior

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in your browser.
3. Click "Use demo" or enter the demo credentials below.
4. Click "Sign in to account".
5. Click "Log out" from the dashboard to end the session.

IMPORTANT
This is a front-end demonstration. Login state is stored in sessionStorage and is not secure authentication.
Do not use real passwords. For a production app, connect a backend with server-side password hashing,
secure sessions/cookies, input validation, HTTPS, and database-backed user accounts.
Internet is only needed for the optional Google Fonts; system fonts will work offline too.
